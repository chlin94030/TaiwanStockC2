# Taiwan Alpha Radar V13.2｜手機優先版

## 這版改了什麼

- 手機字體放大，卡片留白與按鈕尺寸重新調整。
- 主畫面只留：細產業、總評、推薦理由、風險、歷史相似走勢、公司數據、操作。
- 移除首頁宣傳句與重複說明；模型分數收進展開區。
- K 線預設 3 個月，只顯示 K 棒、20 日線、60 日線與成交量；最多 4 個日期刻度。
- K 線高度降為約 430px，價格軸增加上下留白，降低手機窄畫面造成的斜率誇張感。
- 5 日線、120 日線、布林通道改為選配；KD/MACD/RSI 收進「其他技術指標」。

## 最新交易日修正

V13.2 不再只依賴 Yahoo 的最後一根日線。更新順序：

1. Yahoo Finance：多年歷史資料。
2. TWSE / TPEx 官方最新盤後 OpenAPI：覆蓋最新交易日。
3. 若官方 OpenAPI 在雲端失敗或仍落後：
   - 上市改抓 TWSE 日期指定 RWD 盤後資料。
   - 上櫃改抓 TPEx 日期指定 dailyQuotes。
   - 大盤改抓 TWSE 日期指定 RWD 指數資料。
4. 每次掃描都記錄「上市日期／上櫃日期／大盤日期／實際來源」。
5. 系統預期最新完整交易日若為 10/01，但某檔仍停在 09/30，該檔會從本輪排名排除，不再把舊資料當最新推薦。

> 「最新」在本系統指最新**完整交易日盤後資料**，不是盤中逐筆即時報價。

## 個股卡片

每檔顯示：

- 細產業定位，例如「半導體－晶圓代工龍頭」、「電子中游－水冷散熱」。
- 總評與最多 2 個主要推薦理由。
- 主要風險 1 項。
- 歷史相似走勢的中位數、上漲比例、案例數。
- 最新月營收、MoM、YoY。
- 近 4 季 EPS 與累積 EPS。
- 毛利率、本益比。
- 近一月三大法人。
- 有券商分點權限時顯示主力代理資訊。

## 安裝

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Windows 可雙擊 `INSTALL_AND_RUN.bat`。

## 離線測試

```bash
python self_test.py
```

V13.2 測試包含：

- 3y / 8y Yahoo 歷史參數轉換。
- 10 / 40 / 120 日歷史相似走勢模型。
- 進場區與防守價合理性。
- 月營收、EPS、毛利率、PER、法人資料解析。
- 細產業與白話總評。
- 2026-10-02 凌晨應判定最新完整交易日為 2026-10-01。
- 模擬 TWSE OpenAPI 失敗、TPEx OpenAPI 落後一天時，日期指定官方備援仍能把資料庫更新到 2026-10-01。
- 手機 K 線只保留 2 條預設均線、最多 4 個日期刻度。

## 資料來源

- TWSE 官方 OpenAPI / RWD：上市盤後行情與加權指數。
- TPEx 官方 OpenAPI / dailyQuotes：上櫃盤後行情。
- Yahoo Finance / yfinance：多年歷史日線。
- FinMind：月營收、財報、PER、三大法人；券商分點需相應權限。

本工具為研究輔助，不是自動下單或報酬保證。
